LOGO INSTRUCTIONS
=================
Place your logo file here as: logo.png

The site will automatically display it in the navbar and footer.
If the file is missing the text "NEXT RIDES" badge will show as fallback.

Recommended logo specs:
- Format: PNG with transparent background
- Height: 40–60px display height (provide at 2x: 80–120px)
- Width: any (will auto-scale)
